A lightweight menu bar app that shows everything you'd want to know about an iPhone plugged in over USB — battery health, storage, iOS version, hardware, cellular — via libimobiledevice. Sensitive cellular identifiers are masked by default; you choose when to reveal them.iPhoneStatus ne parle qu'à votre propre iPhone, en USB, via libimobiledevice — aucune requête réseau, aucune analytique, aucun backend. Les identifiants cellulaires sensibles sont masqués par défaut ; c'est vous qui décidez de les révéler.iPhoneStatus 只透過 libimobiledevice 以 USB 與你自己的 iPhone 溝通——沒有網路請求、沒有分析追蹤、沒有後端。敏感的行動網路識別碼預設遮蔽，何時顯示由你決定。
